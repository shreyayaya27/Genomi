Qura-Q BrcaDx pilot classical baselines

Scope: pipeline verification only; do not interpret these metrics as meaningful model performance.
Samples: 125 (Tumor=70, Normal=55)
Target: Normal=0, Tumor=1 (verified against metadata.csv)
Features: NEK2, PKMYT1, MMP11, CPA1, COL10A1, HSD17B13, CA4, MYOC, LYVE1

Preprocessing: raw TPM -> log2(TPM + 1) -> StandardScaler.
The scaler is fit separately within each training fold. No feature selection, hyperparameter search, Qiskit, or VQC was used.
Cross-validation: StratifiedKFold(n_splits=5, shuffle=True, random_state=42). Each test fold has 14 Tumor and 11 Normal samples.
Limitation: this remains a small, non-independent pilot cohort; use results for workflow verification, not clinical or generalization claims.

Quantum readiness: nine numerical features can technically encode a 9-qubit model (one feature per qubit), but that is not advisable for this 25-sample pilot.
